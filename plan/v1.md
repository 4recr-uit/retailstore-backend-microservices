# Kế Hoạch Tinh Chỉnh Backend Microservices (Retail Store) - v1.md

> **Phiên bản:** v1.0  
> **Ngày khởi tạo:** 2026-10-27  
> **Mục tiêu:** Chuyển đổi sample app `retail-store-sample-app` (AWS containers demo) thành một hệ thống backend microservices hoàn chỉnh, tinh gọn, ổn định cho mục đích triển khai và thực hành DevOps (CI/CD, Docker, Kubernetes, Monitoring, Chaos Engineering).

---

## 1. Định Hướng & Quyết Định Thiết Kế

1. **Phạm vi hệ thống:**
   - Tập trung vào **Backend Microservices**: Catalog (Go), Cart (Go), Orders (Go), Checkout (Python), Recommendations (Python).
   - Hạ tầng đi kèm cục bộ: MySQL, PostgreSQL, LocalStack (SQS emulator nếu cần worker mode).
2. **Quyết định đối với UI (`src/ui`):**
   - **GIỮ LẠI:** Theo yêu cầu của người dùng, service `src/ui/` (Java/Spring Boot) vẫn được bảo lưu nguyên vẹn để phục vụ test cục bộ hoặc chạy demo trực quan khi cần thiết.
   - **Tách biệt vận hành:** Cấu hình Docker Compose sẽ tách thành **2 file riêng biệt**:
     - `docker-compose.yml`: Chỉ chứa các dịch vụ Backend thuần túy và Database/MQ hạ tầng. Mặc định chạy `docker compose up` chỉ khởi động backend, tiết kiệm tối đa tài nguyên RAM/CPU.
     - `docker-compose.ui.yml`: Chứa cấu hình riêng cho service UI (kèm network kết nối tới backend). Khi cần test giao diện web mới gọi thêm file này (ví dụ: `docker compose -f docker-compose.yml -f docker-compose.ui.yml up` hoặc chạy độc lập).
3. **Quyết định đối với Load Generator (`src/load-generator`):**
   - **GIỮ LẠI:** Giữ lại kịch bản Artillery để hỗ trợ test tải, stress test trong các bài thực hành DevOps.
   - Sẽ cập nhật lại kịch bản để có thể bắn tải trực tiếp vào API Gateway / Backend endpoints khi không bật UI.
4. **Nguyên tắc thực thi:**
   - **Phase 1:** Dọn dẹp các tệp tin/thư mục rác upstream (fork artifacts), **không sửa đổi logic code**.
   - **Phase 2:** Chuẩn hóa cấu hình Docker Compose và biến môi trường; không thay đổi logic nghiệp vụ.
   - Các giai đoạn kế tiếp sẽ hợp nhất Compose ở root, chuẩn hóa database dùng chung, tối ưu image container và xây dựng kịch bản CI/CD.

## 2. Danh Mục Các Service Cốt Lõi

| Service | Ngôn ngữ / Framework | Port | Persistence | Messaging | Trạng thái |
|---|---|---|---|---|---|
| **Catalog** | Go (Gin) | `8081` | MySQL (`catalogdb`) | — | Giữ nguyên, tinh chỉnh sau |
| **Cart** | Go (Gin) | `8082` | PostgreSQL (`retaildb`) | SQS (optional worker) | Giữ nguyên, sửa config sau |
| **Orders** | Go | `8083` | PostgreSQL (`retaildb`) | SQS (optional worker) | Giữ nguyên, sửa config sau |
| **Checkout** | Python (FastAPI) | `8085` | PostgreSQL (`retaildb`) | SQS (optional worker) | Giữ nguyên, sửa config sau |
| **Recommendations** | Python (FastAPI) | `8080` | MySQL (`catalogdb`) | — | Giữ nguyên |
| **UI** | Java 21 (Spring Boot) | `8080` (mapped `8888`) | — | — | **Giữ lại theo yêu cầu (chạy on-demand)** |
| **Load Generator** | Node.js (Artillery) | — | — | — | Giữ lại phục vụ DevOps testing |

## 3. Trạng Thái Các Bất Cập Cấu Hình

1. **Đã xử lý ở Phase 2:** Compose con của Cart, Orders, Checkout dùng PostgreSQL thay cho cấu hình DynamoDB, RabbitMQ, Redis lỗi thời; mặc định `APP_MODE=api`.
2. **Đã xử lý sau rà soát:** Các biến trong `.env.example` được nối vào Compose, gồm port host, host/port kết nối DB, credentials, provider, mode, SQS và UI endpoints. Healthcheck DB dùng cùng biến đã cấp cho database.
3. **Đã xử lý sau rà soát:** `src/app/compose.override.yaml` bỏ tham chiếu Redis/RabbitMQ đã xóa. `src/ui/docker-compose.yml` có tồn tại; nhận định thiếu file trước đây không chính xác.
4. **Đã xử lý sau rà soát:** Gỡ plugin Checkstyle trong `src/ui/pom.xml` vì rules ở `src/misc/` đã được xóa ở Phase 1.
5. **Còn lại cho Phase 3:** Hợp nhất Compose ở root, dùng chung PostgreSQL/MySQL, tách UI on-demand và cấu hình LocalStack tùy chọn. `docker-compose.local.yml` vẫn là cấu hình hạ tầng riêng, chưa dùng bộ biến của các Compose con.
6. **Giới hạn xác nhận:** Đã kiểm tra cấu hình bằng Docker Compose và kiểm tra ghi đè biến; chưa xác nhận build/start container thực tế. Luồng Checkout tạo Orders cần được rà soát riêng, không thuộc ba lỗi cấu hình vừa sửa.
